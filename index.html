Submitted

Certified Real-Time Anomaly Detection for IoT Networks with Pre-Deployment Verification

Developed a certified anomaly detection framework for IoT network security using concentration inequalities for weighted Poisson processes. The framework provides formal false-positive guarantees while maintaining real-time inference performance, bridging the gap between theoretical reliability and operational cybersecurity deployment.

Cybersecurity • Machine Learning • Statistical Learning • Anomaly Detection

Submitted

Certified Anomaly Detection for Overdispersed IoT Traffic

Submitted T-IFS research for sums of independent Negative Binomial random variables, extending classical probabilistic guarantees beyond Poisson and sub-Gaussian settings. The work focuses on building theoretical foundations for machine learning systems operating on overdispersed count data, where traditional assumptions frequently break down.

# Eddie Ibokete Portfolio

Professional portfolio website for Edidiong David Ibokete, focused on data science, machine learning, applied AI, research, analytics, and interactive project storytelling.

This portfolio presents selected research work, machine learning projects, data visualization work, certifications, presentations, achievements, and a custom AI portfolio assistant named Ariel.

## Live Portfolio

Visit the live portfolio:

https://eddy-bok.github.io/experience-portfolio/

## Featured Work

The portfolio includes pages for:

- Project Ariel, a retrieval-augmented portfolio AI assistant
- Reciprocal Resource Matching, a capacity-constrained matching algorithm
- Commercial Building Energy Forecasting and Optimization
- Breast Cancer Classification and Model Evaluation
- Smart City Pattern and Anomaly Detection
- Customer Purchase Prediction and Conversion Analytics
- House Price Prediction
- Visualization projects built with Tableau and Power BI
- Research pages for Poisson-CI and Negative-Binomial CI anomaly detection work
